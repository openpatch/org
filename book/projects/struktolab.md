# Struktolab

-![Struktolab logo](/images/logos/struktolab-circle-mixed.svg){width=120}

Struktolab is a web-based structogram (Nassi-Shneiderman diagram) editor and
renderer with code generation. Students build an algorithm as a diagram and can
see the matching source code right away.

## Highlights

- Editor and renderer — use it interactively or embed a read-only diagram.
- Code generation — turn a structogram into source code.
- Embeddable — available as a web component and as a Hyperbook element.
