# Hyperbook

-![Hyperbook logo](/images/logos/hyperbook-plain-mixed.svg){width=120}

Hyperbook is a quick and easy way to build interactive workbooks, that support
modern standards and run superfast. You write your content in Markdown and
Hyperbook turns it into a static website with search, a table of contents,
interactive elements and offline support.

This website is built with Hyperbook.

## Highlights

- Interactive elements — quizzes, code IDEs, structograms, learning maps,
  Excalidraw drawings and more, all written directly in Markdown.
- Static output — the result is plain HTML, CSS and JavaScript that you can host
  anywhere.
- Made for the classroom — bookmarks, protected pages, printing and export are
  built in.
