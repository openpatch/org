# Online-IDE

-![Online-IDE logo](/images/logos/online-ide.png){width=120}

The Online-IDE is a Java-like programming language together with a complete
development environment — compiler, interpreter and debugger — that runs
entirely in the browser, so no installation is needed at school or at home.

This is a fork of
[martin-pabst/Online-IDE-new-compiler](https://github.com/martin-pabst/Online-IDE-new-compiler),
which we maintain and extend. The original project by Martin Pabst is licensed
under the GNU GPL v3, as is this fork.

## Highlights

- Complete toolchain in the browser — students write, run and debug programs
  without installing anything.
- Two variants — the full Online-IDE for schools and a small embedded IDE that
  can be integrated into any website.
- For the classroom — teachers can access the workspaces of their students, so
  homework can be corrected and help given quickly.
- Interactive course — an extensive interactive Java course is available on
  [learnj.de](https://www.learnj.de).
