# Blockflow

-![Blockflow logo](/images/logos/blockflow.svg){width=120}

Blockflow is our fork of the official Scratch editor
([scratchfoundation/scratch-editor](https://github.com/scratchfoundation/scratch-editor)).
The monorepo contains the packages that make up the Scratch editor, and we
maintain it as the base for block-based editors in our tools.

Scratch is a project of the Scratch Foundation. The editor source is available
under the terms given in the
[blockflow repository](https://github.com/openpatch/blockflow).

## Highlights

- Block-based editing — the full Scratch editor, buildable from source.
- Monorepo — all editor packages and support packages in one place.
- A foundation — our starting point for adapting the editor to our own learning
  tools.
