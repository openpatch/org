# Lernen mit Spaß

-![Lernen mit Spaß logo](/images/logos/lms.svg){width=120}

Lernen mit Spaß ("learning with fun") is a collection of mini games for maths
and computer science lessons. One teacher hosts a game, the class joins with a
six-digit code on their own devices, and everyone plays the same game at the
same time.

## Highlights

- Play together — every player answers the same round at the same time, and the
  host sees the class ranked live on a projector.
- Made for real lessons — students can join mid-game with the same code and
  rejoin after closing a tab, and a server restart mid-lesson puts everyone back
  into the round they were in.
- No student accounts — teachers need an account, students only need the code.
- A growing collection — games for maths and computer science lessons, from
  square roots and terms to spreadsheets, Java and Python; one of the games
  runs its tasks on Bitflow.
