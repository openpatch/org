# Classi

-![Classi logo](/images/logos/classi.png){width=120}

Classi is a local-first app for teachers. It stores groups, students, grades,
notes, checklists and material tracking data in encrypted `.classi` libraries,
and automatic backup and restore to a WebDAV server keeps the data safe and
portable across devices.

## Highlights

- Local-first and encrypted — the data stays on the device in an
  SQLCipher-encrypted database, with passphrase setup and a recovery key.
- Many platforms — runs on Android, macOS, Windows and Linux.
- WebUntis integration — import classes and class lists from a live WebUntis
  connection and take over lesson topics and attendance.
