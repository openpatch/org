# Patches

-![Patches logo](/images/logos/patches-colorful.svg){width=120}

Patches is the OpenPatch Design System. It is the React component library that
gives our applications a consistent look and behaviour, and it is published on
npm as `@openpatch/patches`.

## Highlights

- Shared components — the building blocks behind our tools and apps.
- Themeable — light and dark themes based on the OpenPatch brand colors.
- Accessible by default — sensible focus handling and semantics out of the box.
