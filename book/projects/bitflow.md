# Bitflow

-![Bitflow logo](/images/logos/bitflow-plain-mixed.svg){width=120}

Bitflow is a library for creating and conducting dynamic flow-based assessments.
An assessment is modelled as a flow of tasks and actions, which means the path a
student takes can react to the answers they give along the way.

## Highlights

- Flow-based — branch, repeat and adapt an assessment while it is running.
- Composable — tasks, actions and flows are separate building blocks you can
  reuse across assessments.
- Built on the OpenPatch stack — written in TypeScript and React.
